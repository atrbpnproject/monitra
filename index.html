Rekap Tunggakan SPOPP

Ekstensi belum terdeteksi

Tombol Rekap Sekarang menjalankan ekstensi Chrome Rekap Tunggakan Kanwil versi 1.2.0 atau lebih baru. Ekstensi ini belum terpasang, sedang nonaktif, atau versinya masih lama.

Unduh ekstensi (ZIP)

Cara memasang

  1. Ekstrak ZIP ke folder tetap, misalnya Documents\rekap-tunggakan-kanwil. Jangan hapus folder ini setelah dipasang.
  2. Buka alamat chrome://extensions di tab baru
  3. Aktifkan Developer mode di pojok kanan atas.
  4. Klik Load unpacked, lalu pilih folder hasil ekstrak.
  5. Kembali ke halaman ini dan muat ulang (F5).

Sudah terpasang versi lama? Ganti isi foldernya dengan isi ZIP baru, lalu klik ikon muat ulang pada kartu ekstensi di chrome://extensions. Kalau ekstensi sedang nonaktif, nyalakan tombolnya di kartu ekstensi.
