Ekstensi belum terdeteksi

Rekap Sekarang membutuhkan ekstensi Chrome Rekap Tunggakan Kanwil versi 1.2.0 atau lebih baru. Ekstensi itu tidak menjawab di halaman ini. Kemungkinannya: belum terpasang, sedang nonaktif, versinya masih lama, atau baru saja dimuat ulang sehingga halaman ini perlu dimuat ulang (F5).

Unduh ekstensi (ZIP)

Cara memasang

  1. Ekstrak ZIP ke folder tetap, misalnya Documents\rekap-tunggakan-kanwil. Jangan hapus folder ini setelah dipasang.
  2. Buka alamat chrome://extensions di tab baru
  3. Aktifkan Developer mode di pojok kanan atas.
  4. Klik Load unpacked, lalu pilih folder hasil ekstrak.
  5. Kembali ke halaman ini, muat ulang (F5), lalu klik Rekap Sekarang.

Sudah terpasang tetapi nonaktif? Nyalakan tombolnya di kartu ekstensi pada chrome://extensions, lalu muat ulang halaman ini.

Memperbarui ekstensi

Unduh versi terbaru (ZIP)

  1. Ekstrak ZIP, lalu salin isinya ke folder ekstensi lama (timpa semua file). Lokasi folder lama terlihat di kartu ekstensi pada chrome://extensions.
  2. Buka chrome://extensions lalu klik ikon muat ulang (panah melingkar) di kartu Rekap Tunggakan Kanwil.
  3. Muat ulang halaman ini dan halaman dashboard ATR/BPN yang sedang terbuka.
